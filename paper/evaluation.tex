\section{Evaluation}\label{sec:evaluation}
Run \texttt{python run\_experiments.py --config configs/all.yaml}. For each fixed protocol, fault set and honest-input assignment, the model checker enumerates all finite adversary tables when the search space is below \texttt{max\_exec}; otherwise it runs all named strategies and seeded random tables. Counterexamples are replayed into JSON. A no-counterexample result is not a universal theorem unless the checked space is exhaustive.
